# Free Healthcare Printables Kit

Fillable, printable worksheets for health paperwork: appointment log, medication list, provider directory, and insurance tracker. No account needed. Nothing is stored online. Education only — not medical advice.

## What's inside

| Form | What it's for |
|---|---|
| [`kit/appointment-log.md`](kit/appointment-log.md) | A running list of visits — dates, providers, reasons, follow-ups, referrals, tests, and orders (10 blank rows) |
| [`kit/medication-list.md`](kit/medication-list.md) | Prescriptions, over-the-counter drugs, vitamins, supplements — doses, prescriber, pharmacy, start/stop dates, allergies (10 blank rows) |
| [`kit/provider-directory.md`](kit/provider-directory.md) | Doctors, specialists, dentists, pharmacies, labs, therapists — contacts, phones, addresses, portal logins (10 blank rows) |
| [`kit/insurance-tracker.md`](kit/insurance-tracker.md) | Plan info, member ID/group number, copays, deductibles, out-of-pocket max, premium, claims log (10 blank rows) |
| [`dist/health-kit.html`](dist/health-kit.html) | All four forms as one fillable, printable web page (works offline) |

Each form is also available as plain-text Markdown in [`kit/`](kit/) — print it, copy it into a notes app, or adapt it to your needs.

## How to use it

You don't need to install anything or create an account. Everything stays on your device.

### HTML version (fill in your browser, then print)

1. **Open the kit.** Open [`dist/health-kit.html`](dist/health-kit.html) in your browser (Chrome, Safari, Edge, Firefox — any modern browser works). You'll see a cover page followed by one page per form.
2. **Fill it in.** Type directly into the fields on screen. Field labels are paired with each input so the form works with screen readers. Nothing is uploaded, and no account is needed.
3. **Print or save as PDF.** Click **"Print / Save as PDF"** at the top of the page, or use your browser's print dialog (Ctrl+P / Cmd+P). Choose "Save as PDF" if you'd like a digital copy. When you print, the on-screen buttons disappear automatically, leaving just the clean worksheets.
4. **Start over anytime.** Click **Clear all fields** to blank the form, or refresh the page. Nothing leaves your device unless you print, save, or share it yourself.

### Markdown version (print from any Markdown app)

Open any file in [`kit/`](kit/) in a text editor, Markdown viewer, or notes app. Fill in the blanks, save, and print. The tables use empty rows so you can write in them by hand.
